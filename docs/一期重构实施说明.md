# 一期重构实施说明

## 范围

本次重构先交付一个可运行的精简核心版，不再把旧项目的全部复杂度整体搬迁。

- 保留：`API Key` 网关、账号池、模型价格、用户余额、公告、优惠码、错误日志、系统指标。
- 保留：Provider 插件注册机制，支付插件注册机制。
- 保留：SQLite + GORM、单机单二进制部署方向。
- 一期支付：仅接入 `@../gopay/`，支付宝、微信、Stripe 等官方直连渠道放到二期。
- 暂缓：旧版分组体系、联盟返利、大量聚合监控表、复杂后台页面、各类过度扩展点。

## 当前实现

当前仓库已落下一个新的 `server` 精简骨架：

- `server/cmd/sub2api`
  - 单入口，直接启动 HTTP 服务。
- `server/internal/model`
  - 11 张核心表，ID 从 `10000` 起分配。
- `server/internal/provider`
  - Provider 注册表。
  - 已内置 `openai` 兼容型转发 Provider。
- `server/internal/payment`
  - 支付注册表。
  - 已内置 `gopay` HTTP 适配器。
- `server/internal/service`
  - 账户凭据 AES-256-GCM 加密。
  - OAuth 刷新骨架。
  - 账号选择、请求转发、计费落账、充值回调入账。
- `server/internal/handler`
  - 管理 API、支付 API、代理 API。

## 一期接口

- `POST /api/auth/register-admin`
- `GET|POST /api/admin/users`
- `GET|POST /api/admin/api-keys`
- `GET|POST /api/admin/accounts`
- `GET|POST /api/admin/model-prices`
- `GET|POST /api/admin/announcements`
- `GET|POST /api/admin/coupons`
- `GET /api/admin/stats`
- `GET /api/admin/payment-orders`
- `POST /api/admin/payment-orders/refund`

充值与回调：

- `POST /api/payments/orders`
- `POST /api/payments/notify/gopay`

代理入口：

- `POST /v1/chat/completions`
- `POST /v1/responses`
- `POST /v1/embeddings`

## 配置

建议优先通过环境变量配置：

- `SUB2API_ADDR`
- `SUB2API_DB`
- `SUB2API_AES_KEY`
- `SUB2API_PUBLIC_BASE_URL`
- `SUB2API_GOPAY_URL`
- `SUB2API_GOPAY_PID`
- `SUB2API_GOPAY_KEY`
- `SUB2API_GOPAY_TYPE`
